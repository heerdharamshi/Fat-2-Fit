# 🏋️ Fat 2 Fit — Gym & Diet Planner

**Fat 2 Fit** is a beginner-friendly Python-based fitness and diet planning project. It takes basic user information such as age, gender, weight, height, fitness goal, diet preference, and workout level, and generates a personalized fitness plan.

The project is designed to help users understand their basic fitness requirements and follow a simple workout, diet, hydration, and lifestyle routine.

## ✨ Features

- 👤 Collects basic user information
- 🎯 Provides different fitness goals:
  - Stay Fit
  - Improve Stamina
  - Build Strength
- ⚖️ Calculates BMI and displays the BMI category
- 🔥 Estimates daily calorie requirements
- 💧 Calculates suggested daily water intake
- 🏋️ Generates a workout plan based on:
  - Fitness goal
  - Workout level
  - Gender
- 📅 Creates a weekly workout schedule
- 🥗 Provides meal suggestions
- 🌱 Supports vegetarian and non-vegetarian meal plans
- 🩺 Takes existing health conditions into consideration
- 💡 Provides fitness and BMI-based tips
- 🐍 Built using Python
